# 01: Khóa đăng ký và bảo vệ quản trị tài khoản

**What to build:** Chỉ cho phép đăng nhập công khai và giới hạn toàn bộ vòng đời System User cho Super Admin, với kiểm tra quyền tại server thay vì chỉ ẩn giao diện.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Trang login và server actions không còn đường đăng ký công khai.
- [ ] Chỉ Super Admin đang hoạt động được tạo, kích hoạt, khóa hoặc xóa System User.
- [ ] User thường gọi trực tiếp account action bị từ chối mà không thay đổi dữ liệu.
- [ ] Trang giới thiệu dự án và mọi link tới trang đó được xóa.
