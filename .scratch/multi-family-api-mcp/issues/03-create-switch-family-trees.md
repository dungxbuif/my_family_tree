**Blocked by:** 02: Mở rộng schema và backfill production sang Family Tree

**Status:** ready-for-agent

- [ ] Tạo Family Tree và initial Owner diễn ra trong cùng transaction.

- [ ] Cookie/tree ID giả hoặc membership đã bị xóa không thể cấp quyền.
- [ ] Empty state, selector và create form dùng Heritage Modern tokens, không overflow tại 320×568 và 430×932.
