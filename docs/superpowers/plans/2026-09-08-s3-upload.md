# S3 Upload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Family Tree avatar and gallery uploads from Server Actions/local disk to direct RustFS S3 uploads.

**Architecture:** An authenticated API route issues short-lived presigned PUT URLs. Browser components upload image bytes directly to RustFS, then submit only an internal storage URL to existing Server Actions. A server-side storage route reads/deletes private S3 objects.

**Tech Stack:** Next.js 16 route handlers and Server Actions, AWS SDK v3, RustFS S3.

**Spec:** `docs/superpowers/specs/2026-09-08-s3-upload-design.md`

## Global Constraints

- Store S3 secrets only in `/Users/dungxbuif/production/family-tree/.env`.
- Use a dedicated `family-tree` bucket and keep it private.
- Limit image uploads to 10 MiB and JPEG, PNG, WebP or GIF.
