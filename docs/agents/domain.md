# Domain Docs

This repository uses a single domain context.

Before exploring or changing domain behavior:

- Read `GLOSSARY.md` and use its canonical vocabulary.
- Read relevant decisions under `docs/adr/`.
- Surface any contradiction with an ADR instead of silently overriding it.

If a required domain term is missing, use the domain-modeling workflow to resolve and record it. Create glossary entries and ADRs only when a real term or durable trade-off has been settled.
